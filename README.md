# Travel Management System (Java)

A Java Swing based desktop application for managing travel bookings.

## Features
- User login and signup
- Book travel packages
- Hotel booking
- Customer management
- MySQL database integration

## Technologies Used
- Java Swing
- MySQL
- JDBC
- NetBeans

## How to Run
1. Install MySQL
2. Create database `tms`
3. Import tables
4. Run `Splash.java`
